# Wi-Fi Band (Shizuku)

Home-screen widget that switches your Wi-Fi between 5 GHz, 2.4 GHz and Auto
by pinning the access point's BSSID (`cmd wifi connect-network ... -b`).

1. Create a GitHub repo, push this folder to `main`.
2. Actions -> "Build APK" -> download `WifiBand-debug` -> install `app-debug.apk`.
3. Open the app: Allow Shizuku, "Use current network" (while connected), type the password, Save.
4. Add a "Wi-Fi Band" widget (large/small, glass/solid).
